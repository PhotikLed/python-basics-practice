# Практика 1 — Основы Python

Учебный репозиторий с практическими заданиями по курсу «Основы Python» в рамках программы «Прикладной искусственный интеллект» (Яндекс Практикум / УрФУ).

## Содержание

В данном репозитории реализованы решения практических заданий по ключевым темам первого спринта:

1. **`01_dive_in/skills.py` — Погружение в Python:**
   - Анализ статистики навыков разработчиков (`analyze_skills`).
   - Нахождение минимального и максимального процента владения технологиями среди опрошенных.

2. **`02_branching/pool_tiles.py` — Ветвления:**
   - Автоматизация расчета плитки для облицовки бассейнов (`count_tiles`).
   - Поддержка прямоугольных и квадратных бассейнов (значение ширины по умолчанию `None`).
   - Расчет площади облицовки для дна и 4-х стенок.

3. **`03_imported_types/dates.py` — Импортируемые типы данных:**
   - Работа с модулями `datetime` и `timedelta`.
   - Определение русскоязычных названий дней недели (`get_weekday_name`).
   - Вычисление даты «послезавтра» по заданной строковой дате (`get_day_after_tomorrow`).

4. **`04_collections/olympiad.py` — Коллекции:**
   - Обработка результатов олимпиады по программированию (`check_winners`).
   - Проверка вхождения результата студента в топ-3 лучших баллов.

5. **`05_loops/bakery.py` — Итерации и циклы:**
   - Генерация отчета фасовки кондитерских изделий (`print_pack_report`).
   - Проверка кратности числа на 3, 5 и одновременно на 3 и 5 с использованием обратного диапазона `range`.

## Запуск тестов

Для проверки корректности реализованных решений написан набор юнит-тестов на базе `pytest`:

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов
pytest -v
```

Все тесты покрывают как стандартные случаи из условий задач, так и граничные значения.
