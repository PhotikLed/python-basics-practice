# Практика 1 — Основы Python

Учебный репозиторий с практическими заданиями по курсу «Основы Python» (Яндекс Практикум / УрФУ «Прикладной ИИ»).

## Структура репозитория

Здесь собраны решения практических задач тренажёра по темам:
1. Погружение в Python (базовые функции и операторы)
2. Ветвления и условные конструкции
3. Импортируемые типы данных (`datetime`, `timedelta`)
4. Коллекции (списки, кортежи, сортировка)
5. Итерации и циклы (`for`, `range`, условия)

## Запуск тестов

```bash
pip install -r requirements.txt
pytest -v
```
